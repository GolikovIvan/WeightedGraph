# WeightedGraph
Консольное приложение на языке C++ для работы с взвешенными графами. Выполняет поиск кратчайшего пути с помощью алгоритмов Дейсктры, Беллмана-Форда и А*.

## Сборка и запуск

### Подготовка файлов
Для сборки проекта необходимо расположить все исходные файлы в одной папке. В репозитории уже присутствует готовый исполняемый файл "WeightedGraphApp.exe", расположенный в папке "src/x64/Release", который можно запустить сразу после скачивания.

### Компиляция для Windows
1. Откройте решение "WeightedGraphApp.sln" в Visual Studio.
2. Выберите конфигурацию **Release** и платформу **x64**.
3. Выполните сборку: **Сборка - Собрать решение** (или нажмите "Ctrl+Shift+B").
4. Готовый исполняемый файл "WeightedGraphApp.exe" появится в папке "src/x64/Release".

### Компиляция для Linux
Для сборки под Linux требуется установить кросс-компилятор **MinGW-w64** и выполнить команду:
``` bash
x86_64-w64-mingw32-g++ -std=c++17 -static -mwindows main.cpp -o WeightedGraphApp.exe -lcomctl32 -lgdi32 -luser32
```
Полученный файл можно запустить в Linux через Wine:
``` bash
wine WeightedGraphApp.exe
```
