# WeightedGraph
Консольное приложение на языке C++ для работы с взвешенными графами. Выполняет поиск кратчайшего пути с помощью алгоритмов Дейсктры, Беллмана-Форда и А*.

Для работы с программой расположите все файлы в одной папке. В папке x64/Release лежит уже скомпилированное приложение WeightedGraphApp.exe.

В приложении есть раздел "Справка", в котором содержатся основные сведения о работе программы и её функционале.
