# WeightedGraph
Консольное приложение на языке C++ для работы с взвешенными графами. Выполняет поиск кратчайшего пути с помощью алгоритмов Дейсктры, Беллмана-Форда и А*.

## Сборка и запуск

### Подготовка файлов
Для сборки проекта необходимо расположить все исходные файлы в одной папке. В репозитории уже присутствует готовый исполняемый файл "WeightedGraphApp.exe", расположенный в папке "src/x64/Release", который можно запустить сразу после скачивания.

### Компиляция для Windows
1. Откройте решение "WeightedGraphApp.sln" в Visual Studio.
2. Выберите конфигурацию **Release** и платформу **x64**.
3. Выполните сборку: **Сборка - Собрать решение** (или нажмите "Ctrl+Shift+B").
4. Готовый исполняемый файл "WeightedGraphApp.exe" появится в папке "src/x64/Release".

### Компиляция для Linux
Для сборки под Linux требуется установить кросс-компилятор **MinGW-w64** и выполнить команду:
``` bash
x86_64-w64-mingw32-g++ -std=c++17 -static -mwindows main.cpp -o WeightedGraphApp.exe -lcomctl32 -lgdi32 -luser32
```
Полученный файл можно запустить в Linux через Wine:
``` bash
wine WeightedGraphApp.exe
```


## Работа в программе

### Главное окно
После запуска приложения открывается окно с холстом для построения графа и панелью инструментов в верхней части. В нижней части окна отображается строка состояния с подсказками.

### Добавление вершины
Кликните левой кнопкой мыши по свободному месту на холсте — в этой точке появится вершина с уникальным идентификатором. Чтобы переместить уже созданную вершину, зажмите левую кнопку мыши на вершине и перетащите её в нужное место холста.

### Добавление ребра
1. Нажмите кнопку «Добавить ребро» на панели инструментов.
2. В поле в левом верхнем углу введите вес ребра.
3. Кликните по первой вершине (начало ребра), затем по второй (конец ребра) — между ними будет создано ребро.

### Удаление вершины
Нажмите кнопку **Удалить вершину**, затем кликните по вершине, которую нужно удалить. Все связанные с ней рёбра также будут удалены.

### Поиск кратчайшего пути
1. Выберите вершину, которая будет являться началом пути, и нажмите кнопку **Старт**
2. Выберите вершину, которая будет являться концом пути, и нажмите кнопку **Финиш**
3. Выберите алгоритм, с помощью которого будет определён кратчайший путь (Дейкста, Беллман-Форд или А*)
После выбора алгоритма программа подсветит найденный путь и выведет его стоимость в строке состояния.

### Очистка графа
Кнопка **Очистить** полностью удаляет все вершины и рёбра с холста.

### Справка
Кнопка **Справка** открывает окно с кратким описанием возможностей программы и особенностей используемых алгоритмов.
